# Commands Overview

Evict offers a comprehensive set of commands organized into different categories for easy navigation.

## Command Syntax

Commands follow this general syntax:

```
;command [required] (optional)
```

- **Square brackets** `[]` indicate required parameters
- **Parentheses** `()` indicate optional parameters

## Command Categories

### Configuration

Commands for setting up and customizing Evict in your server:

- `;prefix` - Manage server prefixes
- `;alias` - Create command shortcuts
- `;context` - Customize embed colors and emojis

### Moderation

Tools for managing your server:

- `;kick` - Kick members from the server
- `;ban` - Ban members from the server
- `;antinuke` - Protect against malicious administrators

### Utility

Helpful utility commands:

- `;snipe` - View deleted messages
- `;afk` - Set your AFK status
- `;giveaway` - Create and manage giveaways

### Fun

Entertainment commands:

- `;coinflip` - Flip a coin and bet
- `;8ball` - Ask the magic 8-ball
- `;media` - Image manipulation commands

### Information

Get information about users, servers, and more:

- `;userinfo` - View user information
- `;serverinfo` - View server information
- `;avatar` - Display user avatars

### Last.fm

Music tracking and statistics:

- `;nowplaying` - Show your current track
- `;topartists` - View your top artists
- `;whoknows` - See who listens to an artist most

## Command Permissions

Some commands require specific Discord permissions:

- Configuration commands require **Manage Server**
- Moderation commands require **Kick/Ban Members**
- Role commands require **Manage Roles**

## Getting Command Help

For detailed information about a specific command:

```
;help (command)
```

Example: `;help autorole`
