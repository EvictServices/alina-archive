# Social Integration Commands

Connect and lookup profiles from various social platforms.

<details>
<summary>### GitHub</summary>

View GitHub user profiles and repositories.

#### View User Profile

\`\`\`
;github (username)
\`\`\`

Also: `;git`, `;gith`

**Shows:**
- Username and display name
- Bio/description
- Account creation date
- Top 3 repositories by stars
- Repository statistics (stars, forks, language)

**Example:**
\`\`\`
;github octocat
\`\`\`

</details>

---

<details>
<summary>### Roblox</summary>

View Roblox user profiles and information.

#### User Profile

\`\`\`
;roblox (username)
\`\`\`

Also: `;rblx`, `;rbx`

**Shows:**
- Display name and username
- Description/bio
- Account creation date
- Friends, followers, and following counts
- Past usernames
- Group memberships

**Example:**
\`\`\`
;roblox Builderman
\`\`\`

#### Avatar

View user's Roblox avatar:

\`\`\`
;roblox avatar (username)
\`\`\`

Also: `;roblox av`

**Example:**
\`\`\`
;roblox avatar Builderman
\`\`\`

#### Groups

View user's Roblox groups:

\`\`\`
;roblox groups (username)
\`\`\`

Also: `;roblox gs`

Shows all groups the user is a member of with their role and rank.

**Example:**
\`\`\`
;roblox groups Builderman
\`\`\`

</details>

## Tips

- Usernames are case-insensitive
- External profiles update in real-time
- GitHub shows publicly available repositories only
- Roblox profiles must be public to display information
