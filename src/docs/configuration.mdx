# Configuration Commands

Comprehensive server configuration commands for admins to customize and protect their server.

## Prefix Management

Customize how you interact with Evict.

### View Current Prefix
\`\`\`
;prefix
\`\`\`

### Server Prefix
Set a custom prefix for your server (requires Manage Guild):

\`\`\`
;prefix set (prefix)
\`\`\`

Example: `;prefix set !`

- Must be 1-7 characters
- Affects all server members

### Personal Prefix
Set your own personal prefix:

\`\`\`
;prefix self (prefix)
;prefix self remove
\`\`\`

Example: `;prefix self .`

<details>
<summary>### Disboard Bump Reminders</summary>

Automated bump reminders every 2 hours after someone bumps with Disboard.

#### Enable/Disable
**Requires:** Manage Channels

\`\`\`
;disboard toggle
\`\`\`

#### Set Channel
\`\`\`
;disboard channel (channel)
;disboard channel remove
\`\`\`

Without setting a channel, reminders go to the last bumped channel.

#### Custom Message
**Requires:** Manage Channels

\`\`\`
;disboard message (script)
;disboard message remove
\`\`\`

**Variables:**
- `\\{user\\}` - User who bumped
- `\\{disboard\\}` - Disboard bot mention

Example:
\`\`\`
;disboard message \\{user\\}, thanks for bumping! Bump again with \\{disboard\\}
\`\`\`

#### Thank You Message
Configure automatic thanks when someone bumps:

\`\`\`
;disboard message thank (script)
\`\`\`

</details>

<details>
<summary>### Invoke Messages</summary>

Custom messages for moderation actions. **Requires:** Manage Guild

#### Available Actions
- kick
- ban
- mute
- unmute

#### Set Custom Message
\`\`\`
;invoke (action) (script)
\`\`\`

Example:
\`\`\`
;invoke kick \\{embed\\}\\{title: Kicked\\}\\{description: \\{user\\} was kicked\\}\\{$end\\}
\`\`\`

#### View Message
\`\`\`
;invoke (action) view
\`\`\`

#### Remove Custom Message
\`\`\`
;invoke (action) delete
\`\`\`

</details>
