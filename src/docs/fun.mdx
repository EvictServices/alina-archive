# Fun Commands

Entertainment commands including games, roleplay actions, media manipulation, and economy system.

## Basic Fun Commands

### Choose
Make a decision for you:

\`\`\`
;choose (options)
\`\`\`

Example: `;choose pizza, burgers, sushi`

Supports comma, pipe, or space separation.

### Percentage Commands

Check various percentages (0-100%):

\`\`\`
;gay (member)
;lesbian (member)
;how retarded (member)
;trans (member)
;hot (member)
;cute (member)
\`\`\`

If no member is specified, checks yourself.

### Dih Size

\`\`\`
;dih (member)
\`\`\`

Also known as `;penis`

### Magic 8-Ball

Ask the magic 8-ball a question:

\`\`\`
;8ball (question)
\`\`\`

Also: `;eightball`, `;ball`

### Quote Generator

Generate a quote image from a message:

\`\`\`
;quote (message link or reply)
\`\`\`

Also: `;transfer`, `;send`, `;pay`

**Money Rain:**

**Coin Flip:**

## Tips

- Most commands default to yourself if no member is specified
- Gambling games use the economy system
- Media commands may take a moment to generate
