# Website Launch

Welcome to the new **Evict** website! We're excited to launch this completely redesigned experience.

## Features

### Commands Browser
Browse all available bot commands with:
- Category-based organization
- Real-time search
- Detailed command information

### Status Dashboard  
Monitor the bot's health in real-time:
- Cluster and shard information
- Latency metrics
- Server and user counts
- Top command usage statistics

### Embed Builder
Create beautiful Discord embeds with our interactive builder featuring:
- Live preview
- Multiple customization options
- Variable support
- Export functionality

## Technical Stack

Built with modern technologies:
- **Next.js 16** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Redis** - Caching layer
- **PostgreSQL** - Database
