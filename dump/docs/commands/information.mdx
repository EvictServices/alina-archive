# Information Commands

Lookup information about users, servers, and more.

## Bot Information

### Bot Info
View information about Evict:

\`\`\`
;botinfo
\`\`\`

Also: `;bi`

Shows statistics, system info, and GitHub details.

### Support Server
Get the support server invite:

\`\`\`
;support
\`\`\`

### Invite Bot
Get Evict's invite link or another bot's:

\`\`\`
;invite [bot]
\`\`\`

Also: `;inv`

### Credits
View developer credits:

\`\`\`
;credits
\`\`\`

---

## User Information

### Avatar
View someone's avatar:

\`\`\`
;avatar [user]
\`\`\`

Also: `;av`, `;pfp`

### Banner
View someone's banner:

\`\`\`
;banner [user]
\`\`\`

Also: `;background`, `;bg`

### Server Avatar
View member's server-specific avatar:

\`\`\`
;serveravatar [member]
\`\`\`

Also: `;sav`

### Member Banner
View member's server-specific banner:

\`\`\`
;memberbanner [member]
\`\`\`

Also: `;mb`

### User Info
View detailed user information:

\`\`\`
;userinfo [user]
\`\`\`

Also: `;ui`

Shows: creation date, join date, roles, boost status, devices, activity

### Permissions
View someone's permissions:

\`\`\`
;permissions [member]
\`\`\`

Also: `;perms`

### Spotify
View someone's Spotify activity:

\`\`\`
;spotify [member]
\`\`\`

Also: `;sp`

Shows currently playing song with album artwork.

## Server Information

### Server Info
View server information:

\`\`\`
;serverinfo [server_id]
\`\`\`

Also: `;si`, `;sinfo`

Shows: member count, boost level, creation date, owner, and more.

### Server Icon
View server icon:

\`\`\`
;server icon [invite]
\`\`\`

Also: `;servericon`, `;sicon`

### Server Banner
View server banner:

\`\`\`
;server banner [invite]
\`\`\`

Also: `;serverbanner`, `;sb`

### Member Count
View server member statistics:

\`\`\`
;server count [server_id]
\`\`\`

Also: `;membercount`, `;mc`, `;sc`

### Invite Info
View information about an invite:

\`\`\`
;inviteinfo (invite)
\`\`\`

Also: `;ii`

### Role Info
View information about a role:

\`\`\`
;roleinfo [role]
\`\`\`

Also: `;ri`, `;rinfo`

### Roles List
List all server roles:

\`\`\`
;roles
\`\`\`

Also: `;rls`

### In Role
See who has a role:

\`\`\`
;inrole [role]
\`\`\`

Also: `;ir`

### Emojis
List server emojis:

\`\`\`
;emojis
\`\`\`

Also: `;emotes`

### Stickers
List server stickers:

\`\`\`
;stickers
\`\`\`

### Bots
List bots in the server:

\`\`\`
;bots
\`\`\`

### Boosters
List server boosters:

\`\`\`
;boosters
\`\`\`

Shows who boosted and when.

### Ban List
View banned members (requires: Ban Members):

\`\`\`
;bans
\`\`\`

Also: `;banlist`

### Invites
List active server invites (requires: Manage Guild):

\`\`\`
;invites
\`\`\`

Also: `;serverinvites`

### Recent Joins
See who joined recently:

\`\`\`
;joins [timespan]
\`\`\`

Also: `;joined`

Examples:
- `;joins 1d` - Last 24 hours
- `;joins 1w` - Last week
- `;joins 3m` - Last 3 months

Timespans: s (seconds), m (minutes/months), h (hours), d (days), w (weeks), y (years)

## Utility Lookups

### Dominant Color
Extract dominant color from image:

\`\`\`
;dominant [member] [url]
\`\`\`

Also: `;dom`

Uses your avatar if no parameters provided.

### Urban Dictionary
Define a word:

\`\`\`
;urbandictionary (word)
\`\`\`

Also: `;urban`, `;define`

### Lyrics
Search for song lyrics on Genius:

\`\`\`
;lyrics [query]
\`\`\`

Also: `;lyric`, `;lyr`, `;ly`, `;genius`

If you're listening to Spotify, it auto-detects your current song.

### Weather
Get weather for a location:

\`\`\`
;weather (location)
\`\`\`

Shows temperature, humidity, wind speed, and conditions.

### Cash App
View Cash App user profile:

\`\`\`
;cashapp (username)
\`\`\`

Also: `;cash`, `;ca`

## Tips

- Most commands default to yourself/current server if no parameter provided
- Timestamps show in your local timezone
- Sports commands update in real-time
