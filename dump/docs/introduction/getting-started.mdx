# Getting Started with Evict

Welcome to Evict! This guide will help you set up and start using Evict in your Discord server.

## Adding Evict to Your Server

1. Visit [evict.bot](https://evict.bot)
2. Click the "Invite" button
3. Select your server from the dropdown
4. Authorize the required permissions

## Required Permissions

Evict requires the following permissions to function properly:

- **Manage Messages:** For message management commands
- **Manage Roles:** For auto-role and reaction role features
- **Manage Channels:** For channel configuration
- **Embed Links:** For sending rich embeds
- **Send Messages:** Basic functionality

## First Steps

Once Evict is added to your server, you can:

1. Use `;help` to see all available commands
2. Set up your server prefix with `;prefix set (prefix)`
3. Configure auto-roles with `;autorole`
4. Start customizing embeds with the embed builder

## Getting Help

If you need assistance:

- Join our [support server](https://discord.gg/evict)
- Check out the rest of the documentation
- Use `;help (command)` for specific command help
